GineAssist
GineAssist is a rule-based chatbot developed as part of a Master's project in Applied Artificial Intelligence.

Objective
The objective of GineAssist is to provide general and administrative information for patients of a gynecology clinic through a conversational interface.

The chatbot was developed using Python and NLTK.

Features
GineAssist can answer questions related to:

Clinic hours
Location
Services
Appointments
Consultation costs
Payment methods
Appointment requirements
Appointment rescheduling
Contact information
The chatbot also includes:

Fallback responses
Out-of-scope detection
Emergency detection
Intent classification using rules
Automated functional tests

Limitations
This first version is based on predefined rules and keywords.

The chatbot does not provide medical diagnoses, prescriptions, treatment recommendations, or interpretation of medical results.
